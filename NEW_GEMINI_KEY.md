# Get a Fresh Gemini API Key

The current key has exceeded its daily quota.

1. Go to aistudio.google.com
2. Sign in with ashtonwhales@gmail.com
3. Click "Get API Key" then "Create API key" then Create NEW key
4. Copy the new key
5. Go to render.com > my-frontier-api > Environment
6. Update GEMINI_API_KEY with the new key value
7. Render redeploys automatically

Do this now. Quota resets daily at midnight Pacific time.
The fallback responses will work until the new key is active.
